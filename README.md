# Anomaly Detection — DARPA 1999

Detecção offline de anomalias no tráfego de rede usando o conjunto DARPA 1999 Training Week 2, janelas de **60 segundos** e gráficos de **pacotes por segundo (PPS)**.

Projeto acadêmico em desenvolvimento. O pipeline, instruções de execução e testes serão adicionados no primeiro pull request.

Fonte: https://archive.ll.mit.edu/ideval/data/1999/training/week2/index.html
